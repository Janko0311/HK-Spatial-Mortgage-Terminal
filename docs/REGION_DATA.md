# REGION_DATA.md

## Spatial Layout Strategy
This Phase 1 map does NOT use GIS-accurate boundaries or Blender assets.

Instead, it uses:
- procedural polygon landmasses
- extruded geometry
- stylized relative placement of Hong Kong regions

## Region Positioning
- **New Territories**: large upper landmass
- **Kowloon**: narrower central band between NT and HK Island
- **Hong Kong Island**: lower island mass with denser skyline towers

## Purpose
The goal of Phase 1 is to:
- feel recognizably like Hong Kong
- preserve interactivity
- keep 3D lightweight
- avoid Blender MCP until Phase 3

## Future upgrade path
Later phases may replace these shapes with:
- better procedural coastline data
- stylized district meshes
- Blender-made low-poly terrain and landmarks
